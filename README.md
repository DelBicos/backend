# 💻 DelBicos Backend

API do DelBicos em TypeScript + Express. Postgres (Sequelize) para o negócio, MongoDB para o chat, Stripe para pagamentos, Azure Blob Storage para imagens e documentos, e um serviço de NLP em Python para o chatbot.
